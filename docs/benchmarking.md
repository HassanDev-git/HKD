# Benchmarking HKD

Benchmark results depend on the HKD execution path, Node.js and Zig versions, operating system, architecture, and machine load. Record those details with every run and compare only equivalent workloads and environments.

Use the benchmark runner and workloads maintained for the benchmark process. Supply a new output file for each run so earlier measurements are not overwritten. Confirm workload output and exit status before interpreting timings.

Report medians and raw samples. Do not describe a single host measurement as a general performance guarantee, and do not claim a source-level speedup or regression unless repeated comparable runs support that conclusion. Benchmark reports and raw samples are maintainer evidence and are not part of the public source checkout.
