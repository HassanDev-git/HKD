# HKD Package Manager & Ecosystem Guide

The HKD Package Manager provides reproducible, cryptographic, and offline-capable dependency management.

---

## 1. Defining Dependencies in `hkd.toml`

Dependencies can be sourced from:
1. **The Registry** (SemVer ranges)
2. **Local Paths** (Monorepos & co-located packages)
3. **Hermetic Archives** (`.hkdpack` files)

```toml
[dependencies]
# SemVer Registry Dependency
http = "^1.0.0"
json = "~0.4.0"

# Local Path Dependency
shared-types = { path = "../shared-types" }
```

---

## 2. Managing Dependencies via the CLI

### Adding Dependencies
```bash
# Add from registry with range
hkd add http@^1.0.0

# Add from local directory
hkd add --path ../math-utils

# Add from pre-built archive
hkd add ./vendor/crypto-1.0.0.hkdpack
```

### Inspecting the Dependency Tree
```bash
hkd tree
```
Output:
```text
my-app v0.1.0
├── http v1.2.0
│   └── socket v0.8.1
└── shared-types v0.1.0
```

To export as JSON for CI or automation:
```bash
hkd tree --json
```

## 3. Lockfile Mechanics (`hkd.lock`)

When dependencies are resolved, HKD records the exact dependency graph in `hkd.lock`:

```toml
# This file is automatically generated by HKD. Do not edit manually.
version = 2
resolver = "2.0"

[[package]]
name = "http"
version = "1.2.0"
source = "registry"
checksum = "sha256:d8e8fca2dc5..."
dependencies = [
    "socket 0.8.1",
]
```

### CI and Strict Builds
In continuous integration environments, use `--locked`:
```bash
hkd install --locked
```
If `hkd.lock` is missing or out of sync with `hkd.toml`, the command immediately aborts with error code `error[PKG010]`.

## 4. Packing and Publishing

### Packaging
Create a deterministic `.hkdpack` archive:
```bash
hkd pack
```
This generates `<name>-<version>.hkdpack` containing:
- Magic header (`HKDPACK2\n`)
- Normalized UTF-8 file paths (forward slashes, sorted alphabetically)
- SHA-256 integrity seal
- Decompression bomb and path traversal protections

### Publishing
Publish your library to the registry:
```bash
hkd publish --token $HKD_AUTH_TOKEN
```

---

## 5. Hermetic Offline Builds & Vendoring

To build without any internet connection:
```bash
hkd vendor
```
This copies all resolved packages into `vendor/`. When running with `HKD_OFFLINE=1` or `hkd install --offline`, the compiler links directly against `vendor/`.
